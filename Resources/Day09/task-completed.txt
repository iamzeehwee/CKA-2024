### Task details
1. Create a Service named `myapp` of type `ClusterIP` that exposes port 80 and maps to the target port 80.
  a. Create manifest: vi clusterip-service.yaml
    apiVersion: v1
    kind: Service
    metadata:
      name: myapp
    spec:
      type: ClusterIP
      ports:
        - port: 80
          targetPort: 80
      selector:
        app: v1

  b. Create service: kubectl create -f clusterip-service.yaml
  c. Final Output. Ignore service/kubernetes as it was created by kind:
    NAME                 TYPE        CLUSTER-IP    EXTERNAL-IP   PORT(S)   AGE
    service/kubernetes   ClusterIP   10.96.0.1     <none>        443/TCP   31m
    service/myapp        ClusterIP   10.96.73.87   <none>        80/TCP    5s

2. Create a Deployment named `myapp` that creates 1 replica running the image `nginx:1.23.4-alpine`. Expose the container port 80.

  b. Create Deployment: kubectl create -f deployment.yaml

  c. Final Output. Note that Deployment automatically creates the necessary ReplicaSet and Pods.
