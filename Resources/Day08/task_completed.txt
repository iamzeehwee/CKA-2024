## Task 8/40


In this exercise, you will create a Deployment with multiple replicas. After inspecting the Deployment, you will update its Pod template. You will also be able to use the rollout history to roll back to a previous revision.

## Replicaset

## Deployment
1. Create a Deployment named `nginx` with 3 replicas. The Pods should use the `nginx:1.23.0` image and the name `nginx`. The Deployment uses the label `tier=backend`. The Pod template should use the label `app=v1`.
   a. Create a deployment.yaml
      apiVersion: apps/v1
      kind: Deployment
      metadata:
        name: nginx-deployment
        labels:
          tier: backend
      spec:
        replicas: 3
        selector:
          matchLabels:
            app: v1
        template:
          metadata:
            labels: 
              app: v1
          spec:
            containers:
            - name: nginx
              image: nginx:1.23.0
              
   b. Create the deployment using the yaml: kubectl create -f deployment.yaml
   c. Final Output:

   a. Edit the yaml file: kubectl edit deployment nginx-deployment
   b. Update the image in the yaml file. Once file is saved, pods should be updated via rolling update method whereby a new pod with updated image version is created, once it is running successfully, old pod is terminated. This is done 1 by 1

## Troubleshooting the issue
1. Apply the below YAML and fix the issue with it
   a. Answers are in asterisk

``` YAML
apiVersion: **apps/**v1
kind:  Deployment
metadata:
  name: nginx-deploy
  labels:
    env: demo
spec:
  template:
    metadata:
      labels:
        env: demo
      name: nginx
    spec:
      containers:
      - image: nginx
        name: nginx
        ports:
        - containerPort: 80
  replicas: 3
  selector:
    matchLabels:
      env: demo
```

2. Apply the below YAML and fix the issue with it

``` YAML
apiVersion: **apps/**v1
kind:  Deployment
metadata:
  name: nginx-deploy
  labels:
    env: demo # This must match selector.matchLabels.env
spec:
  template:
    metadata:
      labels:
        env: demo
      name: nginx
    spec:
      containers:
      - image: nginx
        name: nginx
        ports:
        - containerPort: 80
  replicas: 3
  selector:
    matchLabels:
      env: **demo**  # This must match metadata.labels.env
```
